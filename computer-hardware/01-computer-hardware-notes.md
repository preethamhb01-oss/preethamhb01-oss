# Computer Hardware — Student Notes

## 1. What is Computer Hardware?

Computer hardware means the **physical parts of a computer that we can see and touch**.

Examples:
- CPU
- Motherboard
- RAM
- GPU
- SSD/HDD
- Power Supply Unit (PSU)
- Cooling fans
- Monitor
- Keyboard
- Mouse

### Hardware vs Software

**Hardware:** Physical components.

**Software:** Programs and instructions that run on hardware.

Example:
- Keyboard = hardware
- Windows = software
- Chrome = software

## 2. Main Internal Components

### CPU — Central Processing Unit
The CPU executes instructions and performs calculations. It is often called the processor.

Important terms:
- **Core:** An individual processing unit inside a CPU.
- **Thread:** A sequence of instructions that a CPU can manage.
- **Clock speed:** Measured in GHz; indicates operating cycles per second.
- **Cache:** Very fast memory close to the CPU that stores frequently needed data.

### Motherboard
The main circuit board that connects the major components.

It provides connections for:
- CPU
- RAM
- GPU
- Storage
- USB devices
- Network devices
- Power connections

### RAM — Random Access Memory
RAM is temporary working memory used by the computer while programs are running.

Example:
If you open a browser, editor and music player, they use RAM while running.

Remember:
**RAM = temporary working space**
**Storage = long-term data storage**

### GPU — Graphics Processing Unit
A GPU processes graphics and is also useful for highly parallel workloads such as some video editing, 3D rendering and AI tasks.

Two common types:
- **Integrated graphics:** Built into or associated with the CPU and generally shares system memory.
- **Dedicated/discrete GPU:** A separate graphics processor with its own video memory (VRAM).

### Storage

Two common categories:

**HDD**
- Uses spinning magnetic disks
- Usually cheaper per GB
- Mechanical
- Slower than modern SSDs

**SSD**
- Uses flash memory
- No moving parts
- Faster access
- Available in SATA and NVMe forms

### PSU — Power Supply Unit
The PSU converts electrical power from the wall into regulated power used by computer components.

Important factors:
- Wattage
- Efficiency
- Connectors
- Build quality

### Cooling
Computer components produce heat while operating.

Cooling can include:
- Air coolers
- Case fans
- Heat sinks
- Thermal paste
- Liquid cooling systems

Good airflow helps components maintain suitable temperatures.

## 3. External Hardware

Common peripherals include:
- Monitor
- Keyboard
- Mouse
- Speakers/headphones
- Webcam
- Microphone
- Printer
- External storage

## 4. How the Components Work Together

A simplified process:

**Power → Motherboard → CPU/RAM → Storage → Operating System → Applications → Display**

For example, when you open an application:
1. The application is stored on your SSD/HDD.
2. Data is loaded into RAM.
3. The CPU processes instructions.
4. The GPU may process graphics.
5. The monitor displays the result.

## 5. Important Terms to Remember

| Term | Meaning |
|---|---|
| CPU | Executes instructions |
| GPU | Processes graphics and parallel workloads |
| RAM | Temporary working memory |
| SSD | Fast flash-based storage |
| HDD | Magnetic storage with moving parts |
| Motherboard | Connects major components |
| PSU | Supplies regulated electrical power |
| VRAM | Memory used by a dedicated GPU |
| Cache | Very fast CPU-associated memory |
| PCIe | High-speed expansion interface |

## 6. Quick Revision

**Hardware = physical parts**

**Software = programs/instructions**

**CPU = processing**

**RAM = temporary working memory**

**Storage = saves data**

**GPU = graphics/parallel processing**

**Motherboard = connects components**

**PSU = provides power**

**Cooling = removes heat**

## 7. Beginner Tip

Do not judge a computer only by one specification such as GHz, RAM capacity or GPU model. Real performance depends on the **whole system, workload, component generation, power limits, cooling and software**.
